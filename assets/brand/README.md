# AIInfoRoom brand mark

## Strategic concept: **Glass Room + Info Beam**

| Layer | Meaning |
|--------|---------|
| **Room** | A place you enter for clarity — not a feed you scroll past |
| **Three glass panels** | Echo the Virtual News Studio floating panels; transparency = no-hype proof |
| **Vertical light beam** | The “info” — one clear signal inside the noise (also reads as an abstract **i**) |
| **Open architecture** | Invitation, not a closed black box; fits excited-but-analytical voice |

**Differentiation:** Avoids robot heads, neural nets, and generic “AI sparkles.”  
Owns the channel’s actual visual world (glass + cyan broadcast grade).

## Wordmark rules

- Display: **AIInfoRoom** (no spaces)
- Handle: `@AIInfoRoom` / `@aiinforoom`
- Color split (optional): **AI** cyan · **Info** white · **Room** steel  
- Never: “AlInfoRoom”, “AI Info Room” in logo lockups (space only in body copy if needed)
